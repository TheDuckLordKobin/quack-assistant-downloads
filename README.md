# Quack Assistant

Official Android downloads for Quack Assistant.

## Install

1. Download the newest APK from **Releases**.
2. On Android, tap the downloaded file and allow your browser or Files app to install unknown apps when Android asks.
3. Install, open Quack Assistant, sign in, then allow only the permissions you want to use.

The release is built for modern 64-bit Android phones (arm64-v8a).
